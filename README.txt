# Portfolio Wawa Kartiwa

Template website portofolio pribadi berbasis HTML, CSS, dan JavaScript.

## File
- `index.html` — halaman utama
- `style.css` — desain/responsive
- `script.js` — menu mobile dan tahun otomatis

## Sebelum dipublikasikan
1. Ganti `ISI_EMAIL_ANDA` pada `index.html` dengan email aktif.
2. Ganti kotak `WK` pada bagian profil dengan foto profesional jika diinginkan.
3. Tambahkan link LinkedIn/GitHub/WhatsApp jika diperlukan.
4. Periksa kembali semua informasi CV sebelum dipublikasikan.

## Publikasi gratis
Template ini dapat dipublikasikan melalui GitHub Pages atau layanan hosting statis lain.
